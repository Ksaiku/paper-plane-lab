# 要件定義書：紙飛行機デザインラボ（3D物理シミュレーター）

第1版（2026-11-15）

---

## 1. 目的

- 紙飛行機の形を自分で設計し、3Dの空間で飛ばして、形と飛び方の関係を確かめられるアプリを作る
- 本当の目的は、**AI（Claude Fable）が一回の命令で、何時間かけてどこまで細部を作り込めるかを体験すること**
  - このため、機能の数よりも「物理の正しさ」と「見た目・手触りの作り込み」を重視する

## 2. 利用シーン

- 作った本人が、自分のPCで一人で遊ぶ
- 翼や重りを少しずつ変えては飛ばし、前の結果と比べる
  - 例：「重りを前にずらしたら、まっすぐ遠くまで飛ぶようになった」と目で見て分かる

## 3. 形式・動作環境

- PCのブラウザ（Chrome、Edge）で動く
- 最終成果物は `dist/index.html` の **1ファイル**
  - ダブルクリックで開ける
  - インターネットにつながっていなくても動く（使う部品はすべてファイルの中に入れる）
- 3Dの描画には Three.js（ブラウザで3Dを描くための定番の部品集）を使ってよい
- **重要**：飛び方の計算（物理）は自分で書く。一般的な物理エンジン（物がぶつかる・転がる動きを計算する既製の部品）は使わない
  - 理由：既製の物理エンジンは、翼が空気から受ける力を計算しない。紙飛行機の飛び方の核心は、その力の部分にある
- スマホ対応はしない
- 外部への公開はしない

## 4. 画面の流れ

1. 起動 → 短いタイトル表示 → 設計画面
   - 初回だけ、遊び方の説明を出す（あとからも開ける）
2. 設計画面
   - 左：設計パネル（形・重り・投げ方・環境を変える）
   - 中央：3Dの空間と機体
   - 設計パネルの中に、上から見た2Dの設計図を置く。値を変えるとすぐに図も変わる
3. 「飛ばす」ボタン → 飛行
   - カメラを切り替えられる（追いかけ／横から／上から）
   - 一時停止とスローモーション（0.25倍）ができる
4. 着地 → 結果表示
   - 数字（下の5-4）と、一言解説（なぜそう飛んだか）を出す
5. 設計画面に戻る。軌跡（飛んだ道すじの線）は残し、次の飛行と比べられる

## 5. 仕様

### 5-1. 物理（中心の仕組み）

- **重要**：機体の動きは「前後・左右・上下の移動」と「3方向の回転（機首の上下、左右の傾き、左右の向き）」をすべて計算する
- 機体にかかる力として、少なくとも次を扱う
  - 重力
  - 揚力（翼を持ち上げる力。翼が空気に当たる角度と速さで変わる）
  - 抗力（空気の抵抗。進むのを邪魔する力）
  - 尾翼にかかる力（機体の向きを安定させる働き）
  - 風
- 次の現象が、設計の結果として**自然に**起きること（特別扱いで演出しない）
  - 重心（重さの中心）が前すぎる → 機首が下がり急降下する
  - 重心がちょうどよい → まっすぐ長く滑空する
  - 重心が後ろすぎる → 機首が上がって失速し（翼が空気を受けきれず急に落ちる状態）、波打つように飛ぶ
  - 上反角（翼をV字に持ち上げる角度）がある → 傾いても水平に戻りやすい
  - 尾翼が小さすぎる → 向きが安定せず、くるくる回る
- **重要**：同じ設計・同じ条件なら、毎回まったく同じ飛び方になる
  - 風の揺らぎに乱数を使う場合も、乱数の種（同じ並びの乱数を毎回出すための元の数）を固定する
- **重要**：物理の計算は、決まった時間の刻みで進める。画面の速さ（PCの性能）で飛び方が変わらないようにする
- 計算に使う係数（空気の密度、翼の性能を表す数など）は、現実の紙飛行機として不自然でない値にする。根拠を記録する

### 5-2. 設計できる項目

あとで変えたくなる数は、設定値としてコードの1か所にまとめる。

| 区分 | 項目 | 備考 |
|---|---|---|
| 主翼 | 翼幅（左右の長さ）、翼弦（前後の幅）、後退角（翼を後ろへ傾ける角度）、上反角 | |
| 尾翼 | 水平尾翼の大きさと角度、垂直尾翼の大きさ | 水平尾翼の角度で、機首の上がりやすさが変わる |
| 重り | 前後の位置、重さ | 紙飛行機の先につけるクリップのイメージ |
| 紙 | 紙の厚さ | 重さに影響する |
| 投げ方 | 速さ、角度（上下）、向き（左右）、投げる高さ | |
| 環境 | 風の向きと強さ、上昇気流（地面から上に向かう空気の流れ）のあり／なし | |

- 各項目の範囲と初期値は、設計で決めてよい。決めた値は記録する
- 物理的に作れない形（翼の長さ0など）は選べないようにする

### 5-3. お手本の機体（5種類）

違いが目で見て分かるように作る。既存の作品名・商品名は使わない。

1. 入門型：だれが投げても安定して飛ぶ
2. スピード型：細く尖っていて、速く遠くへ飛ぶ
3. ゆったり型：翼が広く、ゆっくり長く浮かぶ
4. 曲芸型：宙返りしやすい
5. 失敗例：重心が後ろすぎて、うまく飛ばない（直し方を一言解説で示す）

### 5-4. 結果の表示

- 数字：飛距離、滞空時間、最高の高さ、滑空比（1m下がる間に何m前へ進んだか）
- 軌跡：今回の線に加え、前回までの線を最大3本、色を変えて重ねる
- 力の矢印：揚力・抗力・重力を矢印で表示する（表示／非表示を切り替えられる）
- 一言解説：飛び方から理由を1〜2文で出す
  - 例：「重心が後ろすぎて機首が上がり、失速をくり返しました。重りを前へずらしてみましょう」
  - 実際の計算結果（失速した回数、機首の角度の変化など）をもとに出す

### 5-5. 保存

- 設計をブラウザの中に名前をつけて保存できる（最大10個）
- ブラウザを閉じて開き直しても残る

## 6. 見た目・演出の方針

細部は任せる。方向だけ決める。

- 紙らしさ：紙の質感、折り目、光の当たり方、地面に落ちる影
- 世界：明るい草原とゆるやかな丘、空のグラデーション（色が少しずつ変わる塗り方）
- 風が目で見えるようにする（流れる細かい粒など）
- 着地点に目印を出す
- 音：風を切る音（速さで変わる）と着地の音。音声ファイルは使わず、ブラウザの中で音を作る。消音にできる
- 画面の文字はすべて日本語

## 7. 利用環境の制約

- ふつうのノートPCで、カクつかずに動く（目安：毎秒50コマ以上）
- 画面の右上に、毎秒のコマ数を表示できる（表示／非表示を切り替えられる）

## 8. 今回は作らないもの（次の版の候補）

- スマホ対応
- 自分で操縦する機能
- ミッション、スコア、ランキング

## 9. 完成の判定基準

すべて、ユーザーが自分で画面を見て確かめられる形にしている。

1. `dist/index.html` をダブルクリックすると起動する。インターネットを切っても動く
2. 起動してから3回以内のクリックで、最初の1機を飛ばせる
3. お手本の5種類を順に飛ばすと、それぞれ飛び方が目で見て違う
4. 入門型の重りを「前端 → 中央 → 後端」と変えて3回飛ばすと、「急降下」「まっすぐ滑空」「波打つような失速」の3つの違いが見える
5. 上反角0度と10度で、横風の中を飛ばすと、傾いたあとの戻り方が違う
6. 風を強くすると、風下へ流される
7. 同じ設計・同じ条件で2回飛ばすと、結果の数字が完全に一致する
8. 前回までの軌跡が、最大3本重ねて表示される
9. 力の矢印を表示／非表示にできる
10. 着地のあと、一言解説が出る。失敗例の機体では、直し方が書かれている
11. 設計を保存し、ブラウザを閉じて開き直しても残っている
12. 毎秒のコマ数を表示すると、飛行中に50以上を保っている
13. 遊び方の説明を、いつでも開ける
