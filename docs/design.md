# 設計書：紙飛行機デザインラボ

要件は `docs/requirements.md`。ここには「どう作るか」を書く。
係数を変えたら、この文書の表も直すこと（値の正本は `src/core/config.js`）。

---

## 1. 全体の作り

```
src/core/   物理・設計・解析。DOM も Three.js も使わない純粋な計算（Node でテストできる）
  config.js     設定値の1か所まとめ（物理定数・空気力の係数・機体の固定寸法・設計項目の範囲）
  aircraft.js   設計 → 形・重さ・重心・慣性・空気力を受ける面（要素）
  aero.js       空気力の計算、設計の性質の解析（中立点・釣り合い）
  wind.js       風・揺らぎ・上昇気流・地面の高さ・固定の種の乱数
  sim.js        6自由度の運動方程式を固定刻みで解く。飛行の記録と結果の数字
  analysis.js   飛行の記録から特徴を数える（失速回数・宙返り・回転・波・横ずれ…）
  comment.js    一言解説（数えた結果から文を組み立てる）
  presets.js    お手本の5機
src/ui/     画面・3D・操作・音・保存（Three.js は描画だけに使う）
tests/      node --test で走る物理テスト
build.mjs   esbuild で全部まとめ、dist/index.html の1ファイルにする
```

**飛行は「飛ばす」を押した瞬間に最後まで計算し、画面はその記録を再生する。**
- 物理は固定の刻み（1/480秒）で進み、画面のコマ数と無関係 → PCの性能で飛び方が変わらない
- 同じ設定なら同じ記録 → 結果の数字が完全に一致する
- 一時停止・スロー（0.25倍）は、再生の時刻の進め方を変えるだけ
- 計算時間：ふつうの飛行で 10〜40ms、最長（60秒の飛行）で約 0.2 秒

## 2. 座標と状態

- 世界座標：x＝前（投げる正面）、y＝上、z＝右（右手系。Three.js と同じ向き）。単位は m
- 機体座標：x＝機首、y＝上、z＝右翼。原点は重心
- 状態（13個の数）：位置3、速度3、向き（四元数 w,x,y,z：機体→世界）4、角速度（機体座標）3
- 角度の符号：機首上げ＝z軸まわりに＋、右への傾き＝x軸まわりに＋、機首を左へ＝y軸まわりに＋

## 3. 運動方程式（6自由度）

```
位置'   = 速度
速度'   = (R·F空気) / m + (0, -g, 0)            R: 機体→世界の回転
四元数' = ½ · q ⊗ (0, ω)
ω'      = I⁻¹ · ( M空気 − ω × (I·ω) )           オイラーの運動方程式。I は 3×3 の慣性テンソル
```

- 解き方：4次のルンゲ＝クッタ法（RK4）、刻み dt = 1/480 秒。毎ステップ四元数を正規化
- 記録：4ステップごと（120Hz）＋着地の瞬間
- 着地：機体の12個の接触点（機首・後端・胴体の底・翼端・尾翼端・垂直尾翼の先）のどれかが地面に触れたら終了。刻みの途中で触れた瞬間まで線形に戻すので、刻みを変えても着地点がなめらかに収束する
- 打ち切り：60秒、または原点から380m
- 刻みの確かめ：dt を 2倍・半分にしても、お手本5機の飛距離の差は 0.0002m 以下

## 4. 重さ・重心・慣性

機体を小さな質点の集まりにして合計する（`aircraft.js`）。

| 部分 | 面密度 | 備考 |
|---|---|---|
| 主翼 | 紙の面密度 × 2枚重ね | 片翼を5本の帯 × 翼弦方向3点 |
| 水平尾翼・垂直尾翼 | 紙の面密度 × 1枚 | |
| 胴体（下向きの折り返し） | 紙の面密度 × 12枚（機首）→1枚（後端）に直線で減る | 紙飛行機は機首側に折り重ねが集まる |
| 重り | 質点 | 位置 0%＝機首、100%＝後端 |

- 紙の面密度 = 800 kg/m³ × 厚さ（厚さ0.1mmで 80 g/m²：ふつうのコピー用紙）
- 入門型：紙 5.0g ＋ 重り 0.8g ＝ 5.8g（A4のコピー用紙1枚は約5g）。翼面荷重 3.6 N/m²

## 5. 空気力（中心の仕組み）

機体を **14枚の平板要素** に分ける：主翼 片側5本×2、水平尾翼 左右2、垂直尾翼 1、胴体の側面 1。
各要素について、その場所の空気の当たり方から力を出し、合計する。**現象ごとの特別扱いは一切しない。**

### 5-1. 要素1枚の計算

1. その要素の位置 r での、空気に対する速度：`v = v重心 + ω × r − 風`（機体座標）
2. 翼幅方向の成分を除き、翼弦方向 u と法線方向 w に分ける。迎角 `α = atan2(w, |u|)`、動圧 `q = ½ρ(u²+w²)`
3. 係数（αの関数）：
   - 失速の進み具合 σ：|α| が失速角 αs を超えると 0→1 へなめらかに（幅 6°）増える
   - 揚力係数 `CL = (1−σ)·a·α + σ·CD90·sinα·cosα`
   - 抗力係数（揚力にともなう分）`CDl = (1−σ)·k·(aα)² + σ·CD90·sin²α`
   - 摩擦などの抗力 `cd0`（全速度に対して、速度と逆向きに）
4. 力の向き：揚力は「流れに直角で面の表側」、抗力は「流れと逆」
5. 力のかかる位置（圧力中心）：付着流では前縁から翼弦の 1/4、完全に剥がれると 1/2（σ で補間）。後ろ向きに流れるときは後縁側から数える
6. 翼弦まわりの回転を弱めるモーメント（薄翼理論）：`M = −(π/8)·ρ·V·c³·翼幅·(a/2π)·(回転の速さ)`

**エネルギーの保証**：力の向きは「力をかける点での速度」に対して決める。揚力は速度に直角（仕事ゼロ）、抗力は速度と逆（仕事は負）、回転を弱めるモーメントも仕事は負。したがって静かな空気の中では、空気力は必ずエネルギーを奪う側にしか働かない（テスト2で確認）。

### 5-2. 揚力傾斜 a・失速角・誘導抗力

- 有限翼の揚力傾斜（ヘルムボルトの式、後退角つき）：`a = 2π·AR / (2 + √(4 + AR²(1+tan²Λ)))`
  - AR＝アスペクト比（翼幅²÷翼面積）、Λ＝後退角
- 後退翼は「1/4翼弦線に直角な流れ」だけが揚力を作るとして扱う（単純後退翼理論）。要素の軸を後退角ぶん回し、傾斜を a/cosΛ にして合計が上の式に合うようにしてある。横すべりすると風上側の翼の実効後退角が減って揚力が増え、上反角と同じ復元力が自然に出る
- 上反角：左右の翼の法線を実際に傾けてある。横すべり → 風上側の翼の迎角が増える → 風下へ傾くモーメント、が幾何から自然に出る
- 失速角：`αs = 9° + 12°/AR`（11°〜20°に制限）。アスペクト比が小さいほど失速が遅い
- 揚力にともなう抗力：`k = (1−η)/a + η/(π·e·AR)`
  - η＝前縁吸引力の割合。紙は縁が鋭く薄いので、ほとんど働かない（力は板にほぼ垂直）

### 5-3. 尾翼への吹き下ろし

主翼の作る下向きの流れが尾翼の迎角を減らす：`ε = kε · CL主翼 / (π·AR)`。尾翼の迎角から ε を引く（力の向きは変えないので、エネルギーの保証は崩れない）。

### 5-4. 胴体の側面

細長い板として扱う（細長物体の理論）：法線力 `CN = (π·AR/2)·sinα·cosα + CD90·sinα·|sinα|`。
角度に比例する分は前寄り（長さの1/4）、横風の抗力分は側面積の中心にかかる。
胴体は前が深い形なので、垂直尾翼が小さいと左右の向きが不安定になる（機首が風上へ向かない）。

### 5-5. 風

- 平均の風：高さ2mでの風速 U。地面近くは弱い（べき乗則、指数0.15）
- 揺らぎ：波長 2.9〜31m の波を成分ごとに5つ重ねる。強さは U の15%。波の向きと位相は**固定の種**（20261115）の乱数（mulberry32）で決めるので毎回同じ。風に乗って流れる
- 上昇気流：決まった3か所の柱（ガウス分布）。中心で 1.0〜1.3 m/s
- 風が0で上昇気流なしのときは、完全に静かな空気

### 5-6. 投げ方

- 位置 (0, 投げる高さ, 0)、速度は「速さ・上下角・左右角」から。機体の向きは速度の向きに合わせる
- **投げのブレ**：機首を右へ1.5°、右へ1.0°傾けた状態で放す（固定値）。人の手は完全にまっすぐには投げられず、ブレがゼロだと左右の不安定さ（垂直尾翼が小さい等）が永久に現れないため。安定な機体ではすぐ消える

## 6. 係数の値と根拠

| 係数 | 値 | 根拠 |
|---|---|---|
| 重力加速度 g | 9.80665 m/s² | 標準重力 |
| 空気の密度 ρ | 1.20 kg/m³ | 20℃・1気圧の空気 |
| 紙の密度 | 800 kg/m³ | コピー用紙 80 g/m²、厚さ 0.1mm |
| 平板の正面抗力 CD90 | 1.2 | 正方形に近い平板を流れに垂直に置いたときの抗力係数 約1.17（Hoerner, *Fluid-Dynamic Drag*） |
| 翼面の摩擦抗力 cd0 | 0.022（翼面積あたり） | 層流平板の摩擦 2×1.328/√Re ≈ 0.019（Re≈2×10⁴：翼弦8cm・4m/s）＋折り目・縁のぶん |
| 胴体の抗力 cd0 | 0.045（側面積あたり） | 折り重ねの段差・重りの出っ張りを含めて翼面の約2倍 |
| 翼効率 e | 0.8 | 低アスペクト比の平面翼の一般的な値 |
| 前縁吸引力 η | 0.25 | 鋭い縁の薄板ではほぼ失われる（0〜0.5）。全機の最大揚抗比が文献の範囲に入る値 |
| 失速角 | 9°+12°/AR（11〜20°） | 低レイノルズ数の平板翼：AR 3〜6 で 10〜12°、AR 1〜2 で 15〜20°以上（Pelletier & Mueller 2000、Torres & Mueller 2004 の風洞実験の傾向） |
| 失速の幅 | 6° | 平板は失速が急。CL が約0.8から約0.5へ落ちる |
| 吹き下ろし kε | 1.2 | 揚力線理論：翼の位置で CL/(πAR)、はるか後方でその2倍。尾翼は翼のすぐ後ろなので 1〜2 の間 |
| 風のべき指数 | 0.15 | 開けた草地の大気境界層の標準的な値（1/7乗則） |
| 揺らぎの強さ | 15% | 地表近くの乱れの強さ 10〜20% |

### できあがった機体の性能と、現実との比べ

| お手本 | 重さ | 釣り合う速さ | 定常滑空の揚抗比 | 静安定余裕 |
|---|---|---|---|---|
| 入門型 | 5.8g | 3.8 m/s | 5.0 | 14% |
| スピード型 | 10.7g | 8.3 m/s | 3.6 | 8% |
| ゆったり型 | 5.2g | 2.8 m/s | 6.0 | 14% |
| 曲芸型 | 7.1g | 4.1 m/s | 4.2前後 | 26% |

**滑空比の範囲の根拠**（テスト7の許容範囲 2.5〜7.5）：
- 紙飛行機3種の最大揚抗比の報告：矢型（ダート）3.31、中間型 3.95、グライダー型 5.08（"Analysis of Flight Characteristics of Paper Airplanes"、数値流体解析と既存実験の比較。https://www.academia.edu/122645080/ ）
- 低レイノルズ数（数万）の薄い平板翼の風洞実験では、翼単体の最大揚抗比が 5〜8 程度（Pelletier & Mueller 2000 の傾向）。胴体や折り目の抵抗が加わる紙飛行機はそれより低い
- 薄い平板では迎角で圧力中心が動くことが紙飛行機の安定に効く（Li, Goodwill, Wang, Ristroph, *J. Fluid Mech.* 2022）→ 失速にともなう圧力中心の後退（1/4→1/2）を入れた理由
- 飛ぶ速さ：紙飛行機の滑空はおよそ 3〜7 m/s。モデルは 2.8〜8.3 m/s

### 入れていないもの（限界）

- 空気の付加質量（軽い紙では速い動きに少し効く）、地面効果、翼のしなり、失速の履歴（ヒステリシス）
- 着地後のすべり・はね返り（着地した瞬間で止める）
- 木などへの衝突（木は飛行範囲の外にだけ置く）

## 9. 結果の数字の定義（要件 5-4）

- 飛距離：投げた点の真下から着地点（重心）までの水平距離
- 滞空時間：放してから着地までの時間
- 最高の高さ：重心の高さの最大値
- 滑空比：最高点から着地までの「水平に進んだ距離 ÷ 下がった高さ」
- 一言解説：`analysis.js` が記録から数えた値（失速の回数＝主翼の失速割合が0.6を超えた回数、宙返り＝機首の回転が360°進んだ回数、きりもみの回転数、高さの波の数、横ずれ、風下への流され量、着地の角度と速さ）と、`analyzeDesign` の設計の性質（静安定余裕、釣り合う速さ・迎角、左右の向きの安定）から、`comment.js` が文を組み立てる

## 10. 画面の作り（src/ui/）

### 10-1. 画面の流れと状態

`title` → `design` ⇄ `flight` → `result` → `design`

- 起動：タイトルを約1.6秒出して自動で消える。初回だけ遊び方を自動で開く（「はじめる」で閉じる）
  → 3クリック以内で飛ばせる：①はじめる ②飛ばす
- 設計：左にパネル、全面に3D。機体は投げ台の上で、投げる向き・角度に合わせて置く。ドラッグで見回し、ホイールで拡大
- 飛行：パネルは左へしまう。下に操作バー（カメラ3種・一時停止・スロー・やめる）、上に計器
- 結果：数字4つ＋一言解説＋軌跡の凡例。「設計に戻る」で設計へ。軌跡は残る

### 10-3. 部品どうしの約束（API）

向き（四元数）は core では `[w,x,y,z]`、Three.js では `(x,y,z,w)`。渡すときに並べ替える。

```js
// scene/world.js（空・光・影・草原・丘・雲・投げ台・距離の目盛り）
createWorld() → {
  scene,                       // THREE.Scene
  sun,                         // 影を落とす DirectionalLight
  setLaunch(setup),            // 投げ台の高さ・向き
  setWind(setup),              // 草や雲のゆれ
  update(dt, time, focus, camera), // 毎コマ。focus(THREE.Vector3) の周りに影・草を寄せる
}
// scene/effects.js（風の粒・上昇気流・着地の目印）
createEffects(scene) → {
  setEnvironment(setup),       // 風の粒・上昇気流の見た目を設定に合わせる（粒は core の makeWind の風の場で動かす）
  setLandingMarkers(list),     // [{ pos:[x,y,z], color:'#rrggbb', label:'21.1m', current:true }]
  update(dt, time, focus, camera),
}
// scene/plane.js
createPlane() → { group, rebuild(aircraft), setPose(pos, quatWXYZ) }   // group の原点＝重心
// scene/trails.js
createTrails(scene) → { start(rec, color), setTime(t), finish(), archive(), list(), setResolution(w, h), colorForNext() }
// scene/arrows.js
createForceArrows() → { group, update(sample, mass, camera), setVisible(b) }
// scene/aim.js（設計画面で投げる向きを示す矢印）、camera.js（カメラの動かし方）
createAim() → { group, update(setup), setVisible(b) }
createCameraRig(canvas) → { camera, setOrbit(center, opts), setFlight(kind, heading, pos), update(dt, pos, vel), ... }
// panel.js
createPanel(root, { setup, onChange(key, value), onPreset(id), onFly(), onSave(name), onLoad(i), onDelete(i) })
  → { el, setSetup(setup, aircraft, info), setSaves(list), setActivePreset(id|null), setVisible(b), setFlyEnabled(b) }
// blueprint.js
drawBlueprint(canvas, aircraft, info)
// overlays.js
createOverlays(root, handlers) → { showTitle(), openHelp(), closeHelp(), isHelpOpen(), setMode(m), setToggles(o), setFps(n),
  setFlightState(o), updateHud(o), showResult(o), hideResult() }
// audio.js
createAudio() → { unlock(), setMuted(b), isMuted(), flightStart(), flightUpdate({speed, stall, rate, paused}), flightEnd(), land(speed), ui(kind) }
// storage.js
loadState(), saveState(state), addSave(state, name, setup), deleteSave(state, i)
```

### 10-4. 見た目の方針

- 明るい昼の草原。空は上が青・地平線が白っぽい色へのグラデーション。遠くにゆるやかな丘
- 紙：白に近いオフホワイト、細かい繊維の模様、折り目の線、やわらかい影
- 画面部品：クリーム色の紙のようなパネル、角丸、やわらかい影。文字はすべて日本語
- 色：空色（操作）、オレンジ（飛ばすボタン・今回の軌跡）、力の矢印は 揚力＝青、抗力＝赤、重力＝黄緑
- 軌跡の色は4色を順に使う（今回は太く、前回までは細く）

### 10-5. 速さの目安（毎秒50コマ以上）

- 物理は飛ばす瞬間に計算済みなので、飛行中の負荷は描画だけ
- 影は1枚（2048×2048）で機体の周りだけ。草は InstancedMesh、粒は Points
- 画素の密度は最大 2 倍まで
